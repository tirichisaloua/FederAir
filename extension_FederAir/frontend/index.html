DATA MINIMIZATION

Seuil minimal de groupe

Un agrégat n'est publié que si le groupe contient au moins trois jours. Ce seuil n'est pas une preuve de k-anonymat.

MINIMUM GROUP SIZE = 3

HTTP 429 · BUDGET EXCEEDED
